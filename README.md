# GISD:Generation of corner cases in infrared autonomous driving dataset with stable diffusion

This dataset addresses corner cases that can occur in the long wave infrared(LWIR) domain with 1000 different images, 512x512 in size. Download [HERE](https://drive.google.com/drive/folders/1WN7RhfocbnYvQziVSQAcRU9PoGHeqpbd?usp=sharing).
